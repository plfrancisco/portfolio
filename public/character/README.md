## Observações

- Fundo é **sólido** (`#0E1116`), não transparente. Se for usar o personagem
  "flutuando" sobre outra cor, gerar versão recortada como `*-cutout.png`.
- JPG como veio do Gemini; o build gera as versões otimizadas (webp/avif).
- Não renomear sem atualizar as referências no código.
- Duplicatas já removidas (a pose "scout" tinha vindo 3×).
